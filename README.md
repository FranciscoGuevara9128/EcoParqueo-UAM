# EcoParqueo UAM 🌿🚗

## 📝 Descripción del Proyecto
La aplicación busca solucionar la congestión vehicular interna y la falta de información en tiempo real sobre la disponibilidad de estacionamientos en el campus. Permite la transición de registros manuales en papel a un sistema digital eficiente para el personal de seguridad y los estudiantes.

## 🛠️ Tecnologías Utilizadas
* **Lenguaje:** Kotlin
* **Interfaz:** Jetpack Compose
* **Entorno:** Android Studio
* **Arquitectura:** MVVM (Model-View-ViewModel)
* **Base de Datos:** Supabase (almacenamiento en tiempo real)

## 📱 Funcionalidades Principales

### Para Estudiantes
* **Editar Perfil:** Gestión de datos del vehículo (Placa, Modelo, Color).
* **Ver Parqueos:** Consulta de disponibilidad en Parqueo Plazoleta y Recepción.
* **Información Detallada:** Ubicación y capacidad de cada zona.

### Para Guardas de Seguridad
* **Selección de Punto de Control:** Gestión desde Agujas o áreas específicas.
* **Registro Vehicular:** Control digital de ingreso y salida mediante placas.
* **Checklist en Vivo:** Visualización de vehículos registrados.

## 🚀 Instalación y Ejecución
1. Clonar el repositorio: `git clone https://github.com/[TU_USUARIO]/EcoParqueo-UAM.git`
2. Abrir el proyecto en **Android Studio**.
3. Sincronizar los archivos de **Gradle**.
4. Ejecutar en un emulador o dispositivo físico con **Android 12 (API 31)** o superior.
